## درباره بازی

**LAST STOP — LINE 13** یک بازی FPS مستقل و تک‌نفره است که در ایستگاه‌های متروی شهر می‌گذرد. هر مرحله یک موج از دشمنان را پیش روی شما می‌گذارد؛ باید پلتفرم را حفظ کنید، مهمات را مدیریت کنید و پس از پاک‌سازی منطقه، به واگن میانی قطار سوار شوید تا به ایستگاه بعدی بروید. بازی پایانی ندارد و هر ایستگاه سخت‌تر از قبلی است.

بازی به‌صورت یک فایل HTML مستقل ساخته می‌شود و پس از ساخت، بدون نیاز به اینترنت یا نصب چیزی در مرورگر اجرا می‌شود.

## ویژگی‌ها

- **دنیای سه‌بعدی رویه‌ای (Procedural):** ایستگاه‌ها، تونل‌ها، قطار و جزئیات محیط به‌صورت کد ساخته می‌شوند.
- **سه سلاح با حس متفاوت:** پیستول نیمه‌خودکار، SMG تمام‌خودکار و شاتگان پمپی.
- **سه نوع دشمن:** مهاجم سریع، تیرانداز از راه دور و غول زره‌پوش.
- **حلقه بی‌پایان گیم‌پلی:** موج → پاک‌سازی → ورود قطار → سوار شدن → ایستگاه جدید → موج سخت‌تر.
- **شش تم ایستگاه:** هر ایستگاه نورپردازی، رنگ و فضای صوتی مخصوص خودش را دارد و تم‌ها بعد از ایستگاه ششم دوباره تکرار می‌شوند.
- **HUD کامل:** نقشه کوچک، شمارش موج، سلامت، زره، مهمات، نشانگر آسیب، فید کشتن و پیام‌های مأموریت.
- **صدای رویه‌ای:** موسیقی و افکت‌ها با Web Audio API ساخته می‌شوند و به فایل صوتی خارجی نیاز ندارند.
- **آیتم‌های salvage:** جعبه مهمات، پلیت زره و ژل درمانی.
- **آمار پایان بازی:** تعداد موج‌ها، کشته‌ها، دقت تیراندازی و زمان بقا؛ بهترین رکورد در مرورگر ذخیره می‌شود.
- **بدون وابستگی خارجی در زمان اجرا:** Three.js، فونت‌ها، استایل‌ها و کد بازی همه داخل `index.html` جاسازی شده‌اند.

## اجرای سریع

نیازی به نصب یا build نیست؛ فایل ساخته‌شده از قبل در پروژه موجود است:

1. فایل `index.html` را با مرورگر مدرن (Chrome، Edge یا Firefox) باز کنید.
2. روی دکمه **ENTER THE PLATFORM** کلیک کنید.
3. برای فعال شدن کنترل ماوس، یک‌بار روی صفحه بازی کلیک کنید (Pointer Lock).

> **نکته:** باز کردن مستقیم فایل با دوبار کلیک هم کار می‌کند. اگر مرورگر شما محدودیت فایل محلی دارد، پروژه را با یک سرور محلی سرو کنید:
>
> ```bash
> python -m http.server 8000
> ```
>
> سپس آدرس `http://localhost:8000` را باز کنید.

برای اجرای بهتر، از هدفون استفاده کنید و بازی را در حالت تمام‌صفحه (F11) ببرید.

## کنترل‌ها

| کلید | عملکرد |
| --- | --- |
| `W` `A` `S` `D` | حرکت |
| ماوس | چرخش دید و نشانه‌گیری |
| کلیک چپ | شلیک |
| کلیک راست | نشانه‌گیری دقیق (ADS) |
| `R` | خشاب‌گذاری |
| `E` | تعامل / سوار شدن به واگن |
| `1` `2` `3` | انتخاب سلاح |
| چرخ ماوس | تغییر سلاح |
| `Shift` | دویدن (فقط هنگام حرکت به جلو) |
| `Space` | پرش |
| `Esc` یا `P` | توقف / ادامه بازی |
| `M` | قطع یا وصل کردن صدا |

> کنترل‌ها برای کیبورد و ماوس طراحی شده‌اند. نسخه موبایل یا گیم‌پد در حال حاضر پشتیبانی نمی‌شود.

## حلقه گیم‌پلی

1. **موج را پاک کنید:** دشمنان از تونل‌های سرویس وارد می‌شوند. تعداد آن‌ها هر موج بیشتر و ترکیبشان سنگین‌تر می‌شود.
2. **ایستگاه امن می‌شود:** پس از نابودی آخرین دشمن، قطار به سمت پلتفرم حرکت می‌کند.
3. **سوار واگن میانی شوید:** به درِ باز واگن نزدیک شوید و `E` را بزنید.
4. **به ایستگاه بعدی بروید:** در مسیر، وضعیت قطار و ایستگاه بعدی نمایش داده می‌شود. در ایستگاه جدید مقدار کمی سلامت و زره بازیابی می‌شود، اما زندگی شما به‌طور کامل پر نمی‌شود.
5. **تکرار:** هر ایستگاه یک Sector جدید است و تا زمانی که زنده بمانید ادامه پیدا می‌کند. بهترین رکورد شما بر اساس تعداد Sectorهای پاک‌شده ثبت می‌شود.

**نکات بقا:** شلیک به سر بیشترین آسیب را می‌زند، شاتگان برای غول‌ها و فاصله نزدیک است، و جعبه‌های مهمات را قبل از خالی شدن کامل خشاب بردارید. جعبه‌ها بعد از مدتی کوتاه از بین می‌روند.

## ساخت و توسعه

### پیش‌نیاز

- Node.js نسخه ۱۶ یا جدیدتر
- هیچ `npm install` یا وابستگی خارجی لازم نیست

### ساخت فایل نهایی

```bash
node build.js
```

اسکریپت `build.js` این کارها را انجام می‌دهد:

1. فونت‌های `src/fonts/*.woff2` را به Base64 تبدیل می‌کند.
2. فایل‌های `src/styles.css` و `src/shell.html` را می‌خواند.
3. فایل `three.min.js` را داخل صفحه جاسازی می‌کند.
4. همه فایل‌های `src/game/*.js` را به ترتیب الفبایی می‌خواند، به هم می‌چسباند و داخل یک IIFE قرار می‌دهد.
5. خروجی را در `index.html` می‌نویسد.

خروجی معمولاً حدود ۱ مگابایت است و بدون هیچ فایل جانبی اجرا می‌شود.

> **مهم:** `index.html` یک فایل تولیدشده است. تغییرات را در `src/` بدهید و دوباره `node build.js` را اجرا کنید؛ در غیر این صورت تغییرات شما با build بعدی از بین می‌رود.

### شخصی‌سازی

| چه چیزی را می‌خواهید تغییر دهید؟ | کجا |
| --- | --- |
| آسیب، خشاب، نرخ آتش و دقت سلاح‌ها | `src/game/00-core.js` → `WEAPON_DATA` |
| سلامت، سرعت و رفتار دشمنان | `src/game/31-enemies.js` → `ENEMY_TYPES` |
| تعداد دشمنان هر موج | `src/game/31-enemies.js` → `getEnemyCount` |
| رنگ، نور و نام ایستگاه‌ها | `src/game/00-core.js` → `THEMES` |
| متن‌های منو و HUD | `src/shell.html` |
| ظاهر و استایل | `src/styles.css` |
| سرعت حرکت، پرش و دوربین | `src/game/32-player.js` |

## ذخیره‌سازی

بهترین رکورد در `localStorage` مرورگر با کلید `lastStopBestWaves` ذخیره می‌شود. برای پاک کردن آن، داده‌های سایت را از تنظیمات مرورگر حذف کنید یا در کنسول اجرا کنید:

```js
localStorage.removeItem('lastStopBestWaves');
```

## پشتیبانی مرورگر و محدودیت‌ها

- مرورگرهای دسکتاپ مبتنی بر Chromium (Chrome، Edge) و Firefox توصیه می‌شوند.
- WebGL (ترجیحاً WebGL 2) و Pointer Lock لازم است.
- بازی برای کیبورد و ماوس طراحی شده است؛ کنترل لمسی یا گیم‌پد ندارد.
- صدا فقط پس از اولین کلیک کاربر فعال می‌شود (محدودیت مرورگرها).
- اگر نشانگر ماوس قفل نشد، یک‌بار روی canvas کلیک کنید.
- رزرو مهمات و سلامت بین ایستگاه‌ها حفظ می‌شود، اما هیچ ذخیره میان‌دوره‌ای وجود ندارد؛ بستن صفحه به معنای پایان run است.
